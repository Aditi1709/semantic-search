# Semantic Search using PostgreSQL + pgvector

## 📌 Project Overview

This project implements an AI-powered semantic search system for e-commerce products.

Instead of matching exact keywords, semantic search understands the meaning of a user's query using vector embeddings generated by a Sentence Transformer model.

This project was developed as part of my internship at Ecomentic.

---

## 🛠️ Tech Stack

- Python
- PostgreSQL
- pgvector
- Sentence Transformers (all-MiniLM-L6-v2)
- Pandas
- psycopg

---

## 📂 Dataset

BigBasket Product Dataset

The dataset contains 254 products with information such as:

- Category
- Sub-Category
- Brand
- Product Name
- Description

---

## ⚙️ Workflow

1. Read the dataset using Pandas.
2. Combine product information into a single text.
3. Generate 384-dimensional embeddings using Sentence Transformers.
4. Store embeddings in PostgreSQL using pgvector.
5. Prepare the database for semantic similarity search.
